☁️ 雲端跨裝置同步設定 (Google 試算表 / GitHub Pages)

💡 為什麼需要設定雲端試算表？
若您將網站發布在 GitHub Pages，同仁各自使用個人的手機或護理推車平板作答。為了讓主管在一處看到「全病房所有同仁的即時填答」，最方便零成本的方法是串接 Google Apps Script Web App！

步驟 1：建立 Google 試算表與部署 Apps Script

  1. 建立一份新的 Google 試算表，第一列建立欄位：時間戳記、姓名、職別、分數、合格、錯題數、證書編號。
  2. 點選試算表上方選單「擴充功能」➔「Apps Script」。
  3. 清空編輯器，貼上以下程式碼並點選「部署」➔「新增部署作業」➔ 選擇「網頁應用程式」，將存取權設為「任何人 (Anyone)」：
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(), data.name, data.role, data.score,
    data.passed ? '合格' : '待加強', data.mistakesCount, data.serial
  ]);
  return ContentService.createTextOutput(JSON.stringify({status:'ok'}))
    .setMimeType(ContentService.MimeType.JSON);
}

步驟 2：貼上部署獲得的 Web App URL

儲存後，任何同仁在對決網完成測驗時，就會自動備份傳送到該 Google 試算表！
